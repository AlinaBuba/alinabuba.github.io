# CLAUDE.md: сайт психологині Аліни

Цей файл одночасно є **документацією проєкту** і **готовим промптом**, за яким Claude Code може створити сайт заново (або оновити його, коли з'являться реальні контакти й фото). Спілкуйся українською. Код, ідентифікатори, коміт-меседжі й команди пиши англійською.

## 1. Мета

Статичний двомовний (UA/EN) сайт-візитка психологині для її клієнтів: хто вона, з чим працює, як проходить робота, як записатися. Без каркасів і фреймворків: чистий HTML, CSS і JS, усе вбудоване (inline) в сторінки. Хостинг: GitHub Pages або Netlify, пізніше власний домен.

Перед створенням чи оновленням перевір, чи є ці файли. Якщо їх немає, використовуй заглушки й познач їх (див. п. 8).

### `contacts.md` (у корені репозиторію)

Файл із контактами й посиланнями на соцмережі. Прочитай його повністю, не припускай формату. Орієнтовний вміст: Telegram, Viber, Instagram, Facebook, LinkedIn, пошта, телефон, години роботи, адреса сайту (домен), ПІБ або ФОП власника, GA4 ID. Усе, що є у файлі, треба використати в:

Якщо якогось поля немає, залиш заглушку з `ph()` і скажи про це в підсумку. Не вигадуй номерів, нікнеймів і адрес.

### `photos/` (у корені репозиторію)

Замість заглушки `<figure class="photo">` вставляй `<img>` усередину `.photo` (стилі вже це підтримують). Якщо фото для якоїсь ролі немає, лиши заглушку.

1. **Опитування.** Спершу з'ясуй інформацію про психологиню й запропонуй список сторінок із рекомендаціями. Не починай розробку, доки не погоджені структура й стиль.

3. **Стилі.** Показано 4 макети (HTML-артефакт зі світлою й темною темою): «М'який ранок», «Чиста ясність», «Тепла земля», «Нічне небо». **Обрано «М'який ранок».**
4. **Розробка.** Генератор `tools/build.py` створює всі сторінки, SEO-файли й зображення.
5. **Перевірка.** Запусти `python3 -m http.server`, зроби скриншоти через headless Chrome (десктоп 1280 px і телефон 390 px, світла й темна тема), перевір JSON-LD і відсутність горизонтального скролу.
6. **Фото та контакти.** Інтегруй `contacts.md` і `photos/` (п. 2), вимкни демо-режим, коли контент реальний.

Сам макет-презентація стилів не входить у репозиторій. За потреби відтвори його як HTML-артефакт.

## 5. Технічний стек і правила

- Чистий HTML5, CSS, JS. Без бібліотек і фреймворків. CSS і JS inline у кожній сторінці (генератор вставляє їх), крім шрифтів і зображень.
- `tools/build.py` єдине джерело правди для контенту й шаблону. Правити треба його, потім запускати `python3 tools/build.py`. Не редагуй згенеровані HTML вручну.
- Налаштування у верхній частині `build.py`: `SITE` (домен), `GA_ID`, `DEMO`.
- Адаптивність: mobile-first, `clamp()` для типографіки, CSS grid/flex, мінімальна бічна відступ 20 px з урахуванням `safe-area-inset`, жодного горизонтального скролу.
- Доступність: семантичні `header/nav/main/footer`, skip-link, видимий `:focus-visible`, `aria-*` для меню й банера, `prefers-reduced-motion`, контраст у обох темах.
- Меню на телефоні: кнопка «Меню» показується **лише** на екранах до 760 px і лише коли JS працює (клас `js` на `<html>`). Без JS меню видиме.
- Деталі FAQ через `<details>/<summary>`, відкривається за якорем (`#first-session`).

### Теми (світла й темна)

Токени кольорів на `:root`. Темна тема: `@media (prefers-color-scheme: dark)` з `:root:not([data-theme="light"])` і `:root[data-theme="dark"]`, обидва блоки з `color-scheme: dark`. Перемикач у шапці, вибір у `localStorage` (у `try/catch`), ранній скрипт у `<head>` запобігає миготінню.

### Стиль «М'який ранок»

| Токен | Світла | Темна |
|---|---|---|
| `--bg` | `#F3EFE8` | `#1B211E` |
| `--surface` | `#FBF9F5` | `#232B27` |
| `--alt` (чергові секції) | `#EAE5DA` | `#202824` |
| `--fg` | `#2B3A33` | `#E8EDE7` |
| `--muted` | `#58675F` | `#A3B0A8` |
| `--accent` (шавлія) | `#4F7360` | `#9DBFA9` |
| `--line` | `#DDD7CB` | `#33403A` |

Радіус 18 px, фото в арковій рамці (`border-radius: 999px 999px 18px 18px`). Настрій: затишно, спокійно, тепло. Без декоративного надміру.

### Шрифти (важливо)

Заголовки **Lora**, текст **Onest**. Обидва мають кирилицю. **Fraunces і Figtree не підходять:** у них немає кириличних гліфів, тому українські заголовки показуватимуться запасним шрифтом.

Шрифти self-hosted (без запитів до Google, це краще для приватності й GDPR): `woff2` латиниця й кирилиця, змінні за вагою, `font-display: swap`, `preload` для кириличних файлів. Щоб завантажити їх заново: запит до `fonts.googleapis.com/css2` із сучасним Chrome User-Agent повертає `woff2` з `unicode-range`, беремо блоки `latin` і `cyrillic`, зберігаємо у `/fonts/`, правила `@font-face` у `tools/fonts.css`.

Уникай гліфів поза підмножинами: `₴` (є лише в `cyrillic-ext`) заміняй на «грн», стрілки `→` не використовуй (малюй CSS або SVG).

## 7. SEO

На кожній сторінці й для кожної мови:
- унікальні `<title>` і `meta description` (до ~160 символів);
- `canonical`, `hreflang` (`uk`, `en`, `x-default` → UA);
- Open Graph (`og:type/site_name/title/description/url/locale/locale:alternate/image` + розміри й `alt`) і Twitter `summary_large_image`;
- `theme-color` для світлої й темної тем;
- JSON-LD: `WebSite`; на головній `ProfessionalService` + `Person` (`jobTitle`, `knowsAbout`, `knowsLanguage`, `sameAs` з `contacts.md`); `BreadcrumbList` на внутрішніх; `FAQPage` на FAQ. **Типу `Psychologist` у schema.org немає**, не використовуй його;
- `sitemap.xml` з усіма URL обох мов, `xhtml:link` alternates і `lastmod`; `robots.txt` із посиланням на sitemap;
- `og-image.png` 1200×630 (PNG, бо не всі платформи показують SVG);
- favicon: SVG (адаптується до темної теми) + PNG 32, `apple-touch-icon` 180, `site.webmanifest` з 192/512;
- швидкість: inline CSS/JS, self-hosted `woff2`, `preload` шрифтів, оптимізовані зображення з `width`/`height`;
- `404.html` з `noindex`.

## 8. Демо-режим і заглушки

- `DEMO = True` в `build.py`: на всіх сторінках `<meta name="robots" content="noindex,nofollow">` і жовта смужка «Демо-версія». **Перед справжнім запуском постав `DEMO = False`** (тоді `index,follow`, смужка зникає).
- Усе, що має бути реальним і ще невідоме (освіта, роки, ціни, години, контакти, ПІБ власника), обгортається `ph("...")` і виділяється жовтим. Після інтеграції `contacts.md` і реальних даних такі виділення мають лишатися тільки там, де даних ще немає.
- Не вигадуй і не публікуй фальшивих дипломів, відгуків, сертифікатів чи статистики на реальному сайті. У демо вони позначені як заглушки.

## 9. Google Analytics 4 і згода на cookie

- `GA_ID` у `build.py` (поточний: `G-PJW885J5PS`).
- **Тег GA не вставляється напряму.** Спочатку inline `gtag('consent','default', {analytics_storage:'denied', ad_storage:'denied', ad_user_data:'denied', ad_personalization:'denied', wait_for_update:500})`. Скрипт `gtag.js` завантажується динамічно **тільки після** натискання «Дозволити».
- Банер: «Дозволити» / «Відхилити», вибір у `localStorage` (`cookie-consent`), кнопка «Налаштування cookie» у футері й на сторінці політики. При відмові `consent update → denied` і видалення `_ga*` cookie для домену та батьківських доменів.
- Події (лише після згоди): `cta_click` (label: hero, band, ...), `contact_click` (label: канал), `lang_switch`, `theme_change`, `faq_open` (питання), `scroll_depth` (50 і 90 %). Елементи позначаються `data-track` і `data-label`.
- Не використовуй рекламні функції, Google Signals і персоналізацію.

## 11. Уроки з першої версії (не повторюй)

- Кнопка «Меню» показувалась на десктопі: стиль `.js .burger{display:inline-block}` має бути **всередині** `@media (max-width:760px)`.
- Шрифти без кирилиці (див. п. 5): перевіряй, що вибраний шрифт має кирилицю, ще на етапі макета.
- Вигадані типи schema.org: перевіряй існування типу.
- Не вставляй сніпет GA «як є»: інакше згода на cookie формальна.
- Не публікуй відгуки без письмової згоди клієнтів.
